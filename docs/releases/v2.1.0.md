## 版本成果

- 会话读取、刷新恢复、标签页隔离、主动新建与结束；服务端过期、并发与轮次校验。
- 预设列表、加载、删除及配置回填；预设路由与面试路由内部拆分，维持现有 URL。
- 彩窗风格多页面界面、人物志数据导出与阅读、亚克力背景、风雪及减少动效支持。
- PDF 简历上传前端与错误反馈；后端和解析仍待接入。
- Agent 代码集中迁移至 agent_system，执行图仍为单个 InterviewAgent。
- Python 与前端包版本及锁文件统一为 2.1.0；补齐当前架构与下一版路线图。
