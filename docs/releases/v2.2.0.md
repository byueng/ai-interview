# AI-Interview v2.2.0

整理日期：2026-10-29。本版本面向本地开发与个人练习，交付简历文本分析、配置与预设改进，以及 Docker 一键运行。

[项目首页](../../README.md) · [当前架构](../architecture.md) · [后续路线图](../roadmap.md) · [v2.2 清单归档](../archive/v2.2.0-roadmap.md)

## 本版变化

- 配置与 PDF 简历通过同一个 multipart 请求保存，文件限定在当前会话，限制 10 MiB，校验类型、文件头及读取路径。
- 简历改为本地提取文字后以普通文本发送给模型，无需 PDF 附件能力。pypdf 负责校验，pdfminer.six 提取正文，修复缺少 ToUnicode 的中文 Adobe-GB1 CID 字体乱码。
- 首轮开场与后台简历分析并行；后续轮次等待分析时提供 SSE 进度，结果保存在 `resume_evalute`，简历全文不进入普通会话消息历史。
- 相同配置复用预设，不同配置另存；预设不继承其他会话的简历文件。
- 提供 Docker Compose、Nginx 代理、健康检查、持久化文件卷、`scripts/deploy.sh` 与 macOS `start.command`，默认从本机 8080 端口访问。
- 恢复 InterviewAgent／graph 的模型依赖注入，修正旧测试与 multipart 接口及开场提示词的契约差异；SSE 不再直接返回供应商原始异常，服务端保留异常链用于诊断。
- Python 项目、前端包及锁文件版本统一为 2.2.0；README、架构与版本导航同步更新。

## 使用与升级

- 新环境运行 `./scripts/deploy.sh init`，填写 `.env` 后执行 `./scripts/deploy.sh up`；macOS 可双击 `start.command`。已有 Docker 环境更新代码后执行 `./scripts/deploy.sh up` 重新构建。
- 本地开发执行 `uv sync --locked`，在 `src/frontend` 执行 `npm ci`；重启后端后新建会话。
- 配置接口为 multipart `session_id`、JSON 字符串 `config` 和可选 `file`，成功响应为 `{session_id, resume}`；旧 JSON 配置请求及数字 `200` 响应契约不再适用。
- 后端重启会丢失内存会话；Docker 文件卷保留不意味着会话恢复，请重新创建面试。

## 已知限制与后续工作

- 执行图仍是单 InterviewAgent 的单轮路径；ResumeAgent、共享评价、按主题切片和整场暂停／恢复尚未交付。
- 简历分析后台任务按会话缓存，任务级失效、失败重试及清理待完善。同会话更换简历或岗位可能复用旧任务，当前请新建会话再上传；本版不宣称动态更新已经完整验证。
- 只支持包含文字层的 PDF，扫描件和图片内容需要后续 OCR／多模态方案；复杂布局和其他字体仍可能影响提取。
- 未完成真实供应商端到端验收、全面浏览器视觉审阅及 Windows／Linux 全新机器测试。自动化通过不代表这些场景已通过。
- 检查点仅存在单进程内存；多 worker、跨重启恢复、多用户授权及完整取消机制仍未支持。
