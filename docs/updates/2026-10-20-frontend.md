# 2026-10-20：前端栏目、简历上传与风雪动效

## 依赖修复与网页名称

- 拉取代码后，Windows 本地缺少已在依赖清单及锁文件中声明的 `vue-router`，导致 Vite 无法解析导入。
- 执行 `npm ci` 同步依赖，随后前端构建成功。
- 标签页名称统一为“页面名称 · ai-interview”，首页保留“序厅 · ai-interview”。
- 修改位置：`src/frontend/src/router.ts`、`src/frontend/index.html`。

## PDF 简历上传前端

- 在面试准备页面左侧新增简历上传卡片，支持选择 PDF、展示文件名和大小、上传、错误提示、重试及移除关联。
- 检查扩展名、MIME 类型和空文件；不在前端解析 PDF，不转换为 Base64。
- 使用 `multipart/form-data`，字段 `file` 直接携带原始 PDF。
- 暂定接口：`POST /interview/sessions/{session_id}/resume`；成功响应约定为 `{ "resume": "server/path/to/resume.pdf" }`。
- 返回路径写入 `candidate_config.resume`，随配置保存。上传失败保留原简历关联，移除关联不删除服务器文件。
- 上传期间禁止保存配置及新建会话；离开组件时取消请求。
- 后端接口尚未实现，缺少接口时显示错误，不模拟上传成功。
- 样式经过一次调整后，按用户选择恢复为初版上传卡片。
- 主要文件：`src/frontend/src/components/ResumeUpload.vue`、`src/frontend/src/api/resume.ts`、`src/frontend/src/state/interview.ts`。
- 详细对接约定见 [RESUME_API.md](../../src/frontend/RESUME_API.md)。

- 用户已接受首版，具体人物与内容留待后续完善；本次未实现内容管理或后台存储。
- 主要文件：`src/frontend/src/views/StoriesView.vue`、`src/frontend/src/App.vue`、`src/frontend/src/router.ts`。

## 通用动效

- 添加缓慢移动的环境光、标题与卡片依次入场、按钮箭头和人物封面悬停反馈、表单聚焦反馈及上传图标动画。

- 面试对话场景不显示新增环境光。
- 主要文件：`src/frontend/src/assets/motion.css`。

## 飘雪与寒风（最终保留效果）

- 仅在序厅、人物志列表首页显示；面试准备、面试室及人物故事正文页不显示。
- 雪粒具有不同大小、透明度、速度及轻微模糊，持续飘落并横向摇摆。
- 桌面设置 64 粒雪，窄屏减少为 32 粒；雪粒位于背景层，不拦截点击。
- 增加冷蓝边缘雾和流动雾带，先按用户反馈提高浓度及覆盖范围，随后将雾层与风带透明度降低约 20%，保留风雪层次，减轻遮罩感。
- 最后确认的主风向为从右向左：雪向左下方移动；雾带循环中向左掠过，并过渡回起始位置。
- 切换到后台标签页时暂停雪和雾的动画；减少动效时隐藏整个风雪层。
- 主要文件：`src/frontend/src/components/AmbientSnow.vue`。
