# 萨尔：自由、家园与责任

选择自己的名字，也面对选择的后果

萨尔最早拥有的名字，是别人对他的处置。布莱克摩尔用一个意味着奴隶的称呼，把捡来的兽人婴儿纳入自己的野心：让他学会阅读、战斗和服从，再借他的力量支配更多兽人。这个孩子得到的教育与伤害来自同一座城堡。知识打开了世界，鞭打却不断提醒他，主人只承认工具的价值。

他后来能够离开敦霍尔德，有赖于几个人在这套规则中做出的不同选择。军士长教他控制愤怒，也教他仁慈；塔蕾莎通过书信，把他当作值得倾听的人。逃亡以后，收容所里萎靡的同族又让自由获得了新的重量：走出自己的囚笼，并不等于已经完成了应该做的事。

寻根使他知道自己是杜隆坦的儿子，但血统没有替他完成成长。在战歌氏族，他拒绝以杀死一个人类孩子换取认可；在霜狼氏族，他学习劳动、谦卑，以及不以自我贬损换取接纳。德雷克塔尔传授的萨满之道尤其重要：元素有自己的意志，力量需要请求，关系需要回应。一个曾被占有的人，开始学习怎样与无法占有的世界相处。

奥格瑞姆把毁灭之锤与领导责任交给他时，这种学习进入了更加艰难的阶段。萨尔能用一粒种子的萌发唤起囚徒的希望，也能在战争中召来地震。他会保护降兵与家人，却同样使用威逼和摧毁。塔蕾莎的死亡使他遭遇无法挽回的损失；敦霍尔德的毁灭，则把一个角斗士的逃亡变成了一个领袖必须承担后果的解放战争。

渡海、结盟、共同抵抗燃烧军团，继而为部落建立家园，让他的责任不断扩大。沃金、凯恩与吉安娜所代表的关系，都要求他越过单一族群的经验。和平也因此变得具体：它需要粮食、土地、往来和约束，需要在自己人愤怒时仍愿意查明事实。《仇恨之轮》里的萨尔能够为鲁莽道歉，也必须用强力制止已经发动的攻击。个人之间的信任可以阻挡一次灾难，却不能独自替两个阵营解决所有问题。

灾变临近时，世界的创伤与部落的困境同时向他索取答案。他安排加尔鲁什暂时代行大酋长职责，离开去寻求元素的回应。这一决定有现实压力，也有明确的反对意见。凯恩的警告未被采纳，而此后发生的死亡与分裂，并不会因为萨尔承担着拯救世界的使命便自动消失。

在阿格娜陪伴下重新学习，在时间的裂隙中面对父母，在巨龙的悲痛面前发现劝说的局限，他逐渐卸下必须独自承担一切的姿态。他以萨满的身份协助守护巨龙，后来与众多英雄共同参与对抗死亡之翼；这些功绩真实而重大，也始终建立在他人的选择、牺牲与援助之上。接受古伊尔这个名字，意味着他开始容许自己拥有爱与家庭，容许职责之外的人生成为自身的一部分。

塞拉摩的毁灭却使政治责任重新追上他。吉安娜曾请求干预，他没有接受；当她准备以海啸毁灭奥格瑞玛时，他又必须挺身阻止。阻止新的屠杀，并不能补偿已经失去的城市。昔日朋友之间的裂痕，保留着他两种责任难以相容的痕迹。

到了《战争罪行》，萨尔面对的不只是加尔鲁什的罪行，还有自己的任命、父辈的过失，以及选择本身的重量。他在庭上否认后悔，也无法轻易摆脱曾经的自责；他承认凡人会犯错，必须从中学习。故事在审判后的逃亡危机与尚待履行的承诺处停下。此时的萨尔已经能够选择自己的名字，仍须继续回答另一个问题：当选择改变了别人的命运，他将如何面对留下的后果。
